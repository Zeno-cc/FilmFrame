# 工作区重规划：技术设计

## 方向与范围

采用用户已选择的「胶片索引」方向（`.impeccable/surfaces/app-tsx.md`）。这是一次 Operate 工具的信息架构与视觉重规划，不是营销首页。保留 `App.tsx` 的照片状态、设置状态、工作流分支、渲染结果和导出动作；改动展示组件、CSS、用户可见命名及对应浏览器测试。

## 组件边界

### 空工作区

- `App.tsx` 在无照片时不渲染 `WorkspaceToolbar`，隐藏空状态右栏底部主按钮和移动固定操作栏，确保「选择照片」只有一个主要入口。
- `EmptyDarkroom` 改为标题/说明、照片示意、导入动作三段网格。桌面左侧文案和动作、右侧大画幅；手机按标题、画幅、按钮排列。
- 本地示例照片仅表达「照片进入胶片画幅」，明确标注照片示意，不宣称是用户照片或真实光谱结果。图片与来源记录随应用保存，无第三方运行时请求。
- 保留 `empty-darkroom-film-track`、`empty-darkroom-film-rail`、`empty-darkroom-exposure-frame` 等结构标识、36 秒单轨道动画、3:2 画幅、悬停/聚焦/拖动暂停及减弱动态。胶片不再是整屏空背景，而是照片示意的承载结构。
- 保留审核摄影名言的本地数据、24 小时更新与 `aria-live="off"`，改为低权重行内内容，不使用独立卡片。三步流程以实际顺序保留为「选片、调整、出片」。
- 空状态右栏仅允许胶片型号与本地配方准备信息，不默认展示片边、输出或工程后端。手机空状态无需先打开完整设置才能导入。

### 有照片的工作区

- `AppHeader` 保留品牌、当前一卷状态、设置入口和更多菜单；不再与工作区重复添加、导出操作。
- `WorkspaceToolbar` 改为「照片工作台」，展示「选片 → 调整 → 出片」及真实入选/已出片状态。保留 `#workspace-add-photos`，添加照片为次级操作。
- 出片 tabs 改为「单张」「胶片长条」，继续使用现有 `outputMode`、tab IDs、键盘方向键和条件渲染。
- 冲洗/停止主操作仍由配方面板或移动操作栏触发；有效下载沿用现有结果校验，不新增绕过状态检查的下载按钮。
- `ContactSheet` 的列表语义从「接触印象」改为「照片列表」，`FilmSequenceRail` 的「叙事顺序」改为「出片顺序」，`FilmStripWorkspace` 的「长条审片台」改为「长条预览」。工程组件名不改。

### 设置与渐进披露

- `RecipeInspectorSection` 扩展为 `'all' | 'film' | 'edge' | 'output' | 'recipes'`。`MobileSettingsSheet` 使用四个标准 tabs：胶片、片边、输出、配方。
- 可见面板名称为「调整」，已保存预设为「我的配方」，不再混称「暗房配方」。移动面板同步命名与关闭按钮可访问名称。
- 胶片：胶片型号、支持时的色彩模拟、颗粒强度；光谱计算后端及技术说明进入高级色彩设置。
- 片边：135/经典模式、经典片边文字与起始帧号；物理底片选择、背光、光圈、拉直、灰雾、漏光、帧号/齿孔/颜色/尺寸进入高级渲染设置。模式支持、兼容限制和提示不改。
- 输出：JPG/PNG 和质量；扫描画幅、背景色、快速预览/高清出片进入高级输出设置。单张/长条在工作区选择，不在设置中重复一套状态。
- 我的配方：现有选择、命名、保存、删除与本地持久化不变。
- 使用现有 `Disclosure` 或原生可访问折叠控件，`aria-expanded` 与 `hidden` 反映真实状态；不只以视觉透明度假装功能消失。
- 所有折叠后的设置继续读取同一 `FilmSettings`，不新增第二套表单状态。相关型号或模式不支持时保持现有禁用/回退行为。

## 视觉系统

- 从 `styles/tokens.css` 统一更新语义色，而不是为局部组件硬编码一套新色。采用石墨蓝工作面、石灰白文字、氧化橙主操作、冷青结构线；成功、警告、错误仍独立表达。
- 采用清晰的中文 UI 字体与较有识别度的无衬线标题栈，正文优先可读性。取消「每个标题都有英文小标签」的重复装饰，不等宽显示普通标签。
- 间距与边框服务于任务分组，减少嵌套卡片、全局噪点和同样权重的深色矩形。按钮、输入、tabs、焦点、选中、禁用共享状态规则。
- `RecipeSummaryCard` 去掉品牌色左边条与英文模式缩写，显示真实型号、色彩/片边/输出摘要与待处理状态。
- 保持 `color-scheme: dark`，检查正文对比度、占位符、焦点、选择文本和滚动条。

## 数据与兼容

- 不改变 `FilmSettings`、`ImageItem`、`OutputMode`、本地偏好/配方格式、render keys、Worker 请求、渲染预算、素材尺寸或导出 MIME。
- 仅修改 UI 文案、组件 props 的展示参数及 DOM 结构；保留用户需要的输入 IDs 和可访问名称，确需改名时同步测试。
- 本地示例图是静态视觉素材，不进入上传/渲染管线，不新建 Object URL，也不携带用户数据。
- `App.tsx` 已有未提交的 Worker 超时与物理种子控制修改原样保留，只在其 JSX 与 props 区域做必要局部编辑。

## 测试与验收设计

- 更新 `tests/e2e/frontend-redesign.spec.ts` 的空暗房结构断言：不再要求旧 332px 背景与引言位于胶片之后，而验证新画幅、示意标注、唯一主操作、流程、响应式和动画契约。
- 对直接操作高级参数的测试提供明确的展开动作，不以强制打开全部设置维持旧测试。
- 更新工作区与设置的可访问名称选择器；运行相关浏览器测试，检查真实导入、模式切换、设置、预览、冲洗与导出。
- 检查 1440、1180、768、390px，以及设置展开、长文本、焦点、拖动、减弱动态状态。
- 使用 Impeccable 检测和独立 finish review；新视觉系统由 documenter 写入 `DESIGN.md` 与 `.impeccable/design.json`。

## 回滚与风险

- 风险主要是旧 E2E 名称/几何断言及设置折叠后可发现性；通过明确高级入口、同步测试和实际浏览器检查控制。
- 视觉 token 是共享变更，需要同时检查预览、对话框、移动端设置与反馈组件。
- 不回滚用户已有修改，不创建分支或 worktree，不修改渲染与发布文件；若方案中止，仅对本任务明确修改的文件按补丁反向处理，不执行 destructive Git 操作。
