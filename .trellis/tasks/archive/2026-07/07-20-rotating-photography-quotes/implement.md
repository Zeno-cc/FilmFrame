# 免费摄影名言轮播实施计划

## 1. 建立 Wikiquote 同步工具

- 新增同步脚本和摄影师页面白名单。
- 请求 MediaWiki revisions API，记录页面 ID、修订号、时间戳、URL 和原始 Wikitext。
- 保守提取候选名言，生成独立候选文件和差异报告。
- 增加超时、中止、错误处理和“失败不覆盖旧快照”保护。

## 2. 建立审核快照

- 新增 `data/photography-quotes.json` 及结构校验。
- 首批候选经过人工核验、中文翻译和来源记录后进入生产快照。
- 将候选生成物排除出 Vite 生产构建，只发布审核快照。

## 3. 实现本地轮播逻辑

- 新增名言类型、快照校验、24 小时时段索引与边界延迟纯函数。
- 在 `EmptyDarkroom` 中使用 `<blockquote>` 和 `<cite>`，不显示手动控制或技术说明。
- 使用可清理的单次计时器在下一个 24 小时时段边界本地切换。
- 保留本地处理提示，不添加运行时 API 请求。

## 4. 测试与验证

- 同步测试：正常页面、超时、页面不存在、结构变化、零候选和旧快照保护。
- 数据测试：唯一 ID、必填来源、修订号、文本长度、中文译文和核验日期。
- 前端测试：同一时段稳定、跨时段自动切换、计时器清理和控制元素缺失。
- Playwright：桌面和移动端名言展示、出处链接、无第三方请求、拖拽上传及 390px 无溢出。
- 运行 `npm run check`、`npm run test:e2e`、同步脚本测试和 `git diff --check`。

## 5. 可选免费自动化

- 在第一版稳定后，可增加每周一次的 GitHub Actions 同步任务。
- 自动化只生成候选差异并创建待审核产物，不直接修改生产快照或自动发布。

## 明确限制

- 免费方案不能保证 Wikiquote 覆盖所有摄影师。
- 新增语料需要人工审核和中文翻译，不是完全无人维护。
- 如果未来要求实时远程随机内容，需要重新评估免费接口稳定性和浏览器隐私边界。
