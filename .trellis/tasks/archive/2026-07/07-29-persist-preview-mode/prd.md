# 预览模式跨图片保持与快捷旋转

## Goal

让单图预览中的查看和方向调整保持连贯：用户选择“原图”或“成片”后，切换照片仍沿用该模式；需要纠正方向时，可通过明确按钮或键盘快捷键快速顺时针旋转 90°。

## Background

- `App.tsx:265` 以应用级状态保存 `previewSourceMode`，类型为 `before | after`。
- `App.tsx:1187-1190` 在预览类型或当前照片 ID 变化时执行 `setPreviewSourceMode('after')`，这是翻页后丢失选择的直接原因。
- `PreviewDialog` 已是受控组件，上一张、下一张和键盘方向键最终都只更新当前预览照片，不需要新增组件或持久化服务。
- 每张照片进入预览时都会生成即时成片预览；正式成片不存在时，现有回退链仍可使用即时预览或原图。

## Requirements

- “原图 / 成片”是单图预览器的统一显示偏好，不写入 `ImageItem`，也不改变照片的冲洗、失效或下载状态。
- 用户选择“原图”后，通过上一张、下一张或键盘方向键切换照片，仍显示原图且“原图”按钮保持选中。
- 用户选择“成片”后，以相同方式切换照片，仍保持“成片”按钮选中，并沿用现有即时预览、正式成片和原图回退链。
- 当前页面会话内记住最后一次选择；关闭单图预览后，从接触印象列表重新打开任意照片仍沿用该选择。
- 刷新或重新加载页面后恢复默认“成片”，不跨页面会话持久化。
- 提交新的裁切构图后，继续沿用现有行为切到“成片”，让用户立即看到新构图的渲染结果。
- 将现有图标旋转按钮改为图标加“旋转 90°”文字，继续调用已有顺时针四分之一旋转命令。
- 单图预览打开、未进入裁切且旋转命令可用时，按 `R` 或 `r` 执行一次与按钮完全相同的顺时针 90° 旋转。
- `R` 快捷键忽略按键长按产生的重复事件，且不得在输入框、可编辑元素或裁切编辑状态中触发。
- 长条预览不显示原图/成片切换，不受本任务影响。

## Acceptance Criteria

- [x] 选择“原图”后连续切换上一张、下一张，所有照片均保持原图模式。
- [x] 选择“成片”后连续切换上一张、下一张，所有照片均保持成片模式。
- [x] 鼠标点击导航与键盘 `ArrowLeft` / `ArrowRight` 的行为一致。
- [x] 关闭并重新打开单图预览后仍保持最后选择；刷新页面后恢复默认“成片”。
- [x] 模式切换不会改变任一照片的 transform、冲洗状态、成片 URL 或下载资格。
- [x] 提交裁切后仍切换到成片模式；关闭裁切不改变当前模式。
- [x] 长条预览及其下载行为无回归。
- [x] 使用至少两张照片的 Playwright E2E 覆盖跨图片保持，并通过相关单元测试、类型检查和生产构建。
- [x] 单图预览显示带旋转图标和“旋转 90°”文字的按钮，点击后只顺时针旋转一次。
- [x] 单图预览按 `R` / `r` 与点击按钮效果一致，长按重复事件不连续触发。
- [x] 裁切编辑、长条预览及可编辑控件中按 `R` 不触发快捷旋转。
- [x] 旋转按钮与快捷键具有可访问名称，桌面与移动端工具栏均无溢出。
- [x] Playwright 覆盖按钮与键盘两条旋转路径，并重新通过单元测试、类型检查、生产构建和完整 E2E。

## Out of Scope

- 不将偏好写入 localStorage、配方或 URL。
- 不修改即时预览渲染、Worker、胶片模板、下载或分享逻辑。
- 不增加新的视觉控件、依赖或全局状态库。
- 不增加逆时针、任意角度或可配置快捷键。

## Key Decisions

- 预览模式是 `App` 生命周期内的会话级 UI 偏好，不属于照片数据或用户持久设置。
- 用户主动提交裁切构图是唯一允许自动切换到“成片”的现有操作。
- 快捷键使用单个 `R` 键，仅在单图预览的非裁切状态生效；按钮与快捷键复用同一个旋转回调。
- 任务保持轻量，不新增 `design.md` 或 `implement.md`。
