# P0 完整冲洗与导出闭环

## Goal

消除 ZIP 静默漏图：默认补齐剩余冲洗后导出，同时允许用户明确选择只导出当前有效成片。

## Requirements

- 根据当前选中照片及其渲染身份区分有效成片、待处理、已失效和失败结果。
- 全部结果有效时维持一键导出，不增加无意义确认步骤。
- 结果不完整时打开聚焦确认界面，默认主操作为“冲洗剩余照片并导出”。
- 确认界面同时提供“仅导出当前 N/M 张”，不得把部分导出伪装成完整导出。
- 补齐流程复用现有批处理准入、并发、错误处理和已有结果，不重复处理有效成片。
- 用户停止或补齐失败时不得自动导出；保留已经成功的结果，提供明确状态反馈。
- 长条下载仍只在当前设置对应的长条结果存在时可用，不纳入本任务自动生成范围。

## Acceptance Criteria

- [ ] 所有选中照片都有当前有效成片时，点击 ZIP 直接下载全部结果。
- [ ] 部分完成时，点击 ZIP 显示总数、已完成数和待处理数，默认动作会补齐后只触发一次下载。
- [ ] 用户可明确仅导出当前有效的 `N/M` 张；零张有效时不显示该动作。
- [ ] 补齐过程保留已有有效成片，不处理未选中照片，并遵守现有批处理上限。
- [ ] 补齐失败或被停止时不产生误导性的完整 ZIP，也不清除成功结果。
- [ ] 设置变化导致旧结果失效时，该照片按待处理处理。
- [ ] 单元测试覆盖完整、部分、零结果和失效结果的导出决策；端到端测试覆盖部分完成的两个分支。

## Constraints

- 不改变 ZIP 文件命名、图片编码或 JSZip 边界。
- 不自动纳入用户未选中的照片。
- 不新增全局状态管理或外部依赖。
