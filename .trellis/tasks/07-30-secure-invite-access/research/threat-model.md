# 邀请码门禁威胁模型

## 需要保护的资产

- 官方站点的 HTML、JavaScript、CSS、Worker 和胶片素材。
- 邀请码签发能力、未兑换邀请码、有效会话及撤销状态。
- FilmFrame 原有的本地照片隐私边界。

## 信任边界

- **可信：** 项目所有者本机、受控 SSH 运维通道、源站鉴权服务及其持久化存储、正确配置的 OpenResty。
- **不可信：** 浏览器内 React 状态、`localStorage`、Vite 构建产物、请求参数、Cookie 明文、客户端网络环境和共享缓存。
- **部分可信：** Cloudflare 只在缓存与源站规则正确配置时参与保护；源站仍需独立阻止直连绕过。

## 已确认的主要绕过路径

1. 删除 React 邀请弹窗、修改状态或伪造 `localStorage` 标记。
2. 从 Vite 产物提取固定邀请码、哈希盐、HMAC 密钥或私钥。
3. 不访问首页，直接请求已知 hashed JS、Worker、overlay 或 mask URL。
4. 绕过 Cloudflare/OpenResty，直连当前公开的 Docker 应用端口。
5. 直连源站 443 并伪造 Host/SNI，绕过只部署在边缘的鉴权。
6. 命中门禁启用前的 Cloudflare 或浏览器公开缓存。
7. 重放、分享或并发兑换同一邀请码。
8. 通过 URL、Referer、访问日志或错误日志泄露邀请码或会话。
9. 窃取本机签发秘密，或窃取/固定/篡改会话。
10. 合法用户保存已经下载的前端产物并离线运行或转发。

## 安全上限

服务端门禁可以可靠保护官方分发入口，但不能把已经交付到浏览器的纯前端代码变成不可复制资产。若要阻止第 10 条，只能把核心算法或关键素材移入服务端 API；这会改变 FilmFrame 当前“照片不上传”的产品定位，因此明确排除在本期范围外。

## 必须验证的负面场景

- 无 Cookie、篡改 Cookie、过期 Cookie、撤销 Cookie。
- 随机码、篡改码、过期码、撤销码、已用码、错误版本码和超大请求体。
- 同一一次性邀请码的串行与并发重放。
- 已知静态资源 URL 的匿名请求和缓存命中尝试。
- 公网应用端口、源站直连、伪造转发头和鉴权服务停机。
- 日志、数据库、构建产物和容器镜像的凭据扫描。
