# 联网摄影示意轮换

## Goal

让空暗房的照片示意可定时轮换，并在缓存到期后联网换一批、删除自有旧缓存，同时不损害本地照片隐私、首屏主任务和离线可用性。

## Background

- 用户希望照片示意能联网下载、轮换、过期换批并删除旧图，已于 2026-11-17 确认创建并实施本子任务。
- 当前 `components/workspace/EmptyDarkroom.tsx` 只有一张本地 CC BY 4.0 摄影示意，以及独立摄影名言轮换。
- 马格南与哈苏官方条款没有授予本应用下载、抓取和再分发权限，不接入这两个站点。
- Wikimedia Commons 官方 API 能提供许可元数据，图片响应允许跨域访问；必须在下载时验证来源、作者和许可，不能把可下载等同于可复用。
- 当前 `PRODUCT.md` 禁止将用户照片交给第三方图像处理，但不禁止仅用于公共示意的匿名资源下载。需要明确这一新增网络边界，不能将它混入用户照片处理链路。

## Confirmed Decisions

- 素材（2026-11-17 更新）：从实际审阅过画面的 Dorothea Lange、Gordon Parks、Walker Evans 公共摄影档案中选择 24 张组成轮换池，每批 12 张且避开上一批；按 Commons 作品 ID 精确获取，不依赖题材分类。不抓取马格南／哈苏，不使用摄影师肖像代替其作品。
- 轮换（2026-11-17 更新）：同一空状态区域内多张照片组成连续 3:2 胶片画幅，以固定像素速度持续从右向左运动，可见当前与相邻照片；取消每 12 秒推进一格的停顿，不做单张淡入淡出；无自动焦点移动或状态播报。
- 换批：缓存满 7 天后，在空状态可见且页面联网时获取新一批。
- 删除：新批次全部通过来源、许可、文件类型和体积校验并成功保存后，删除本功能拥有的上一批 Blob 和元数据；不删除用户照片、偏好、配方或内置素材。
- 降级：网络失败时保留旧批次；没有旧批次则保留当前内置摄影示意，不显示空白、错误弹窗或加载占位。

## Requirements

### R1 许可与来源

- 从 Wikimedia Commons 官方 HTTPS API 按已审核作品 ID 获取候选及作者、来源、许可信息。不得用分类里的其他图片替换审核结果。
- 仅接受明确列入允许范围的自由许可，保存原始作品链接、作者、许可名称和许可链接；官方 API 缺少许可 URL 时，只对已接受的许可名称使用其官方规范链接，拒绝缺失或不明许可。
- 只下载官方图片域名的 JPEG/PNG 内容，限制单张大小，拒绝 SVG、HTML、错误内容和超大图片。
- 在示意来源说明中保留可访问的署名、来源和许可链接；继续明确「照片示意 · 非胶片渲染结果」。

### R2 轮换与换批

- 每批 12 张，片轨按实际画幅与间距测量得到的周期持续匀速左移；不使用定时跳格，不以单张淡入淡出替代；不自动移动焦点，不使用 `aria-live` 播报。
- 悬停、键盘聚焦、拖动上传、页面隐藏时暂停实际位移；`prefers-reduced-motion` 禁用运动并保持静态多画幅。完整片轨结束后无感回到相同画面，不出现空白或反向回跳。
- 到期时下载不同候选组成新批次；不能在新批次未完整就绪时替换当前照片或删除旧缓存。
- 同一浏览器避免多个标签页或重复组件造成无界并发、重复换批和持续写入。

### R3 缓存与删除

- 仅使用本功能独立的 IndexedDB 数据库保存示意 Blob 及来源元数据，不进入用户照片的存储、渲染或导出路径。
- 无 Cookie 请求，不向 Wikimedia 发送用户照片、文件名、配方、设置、IP 备注或其他会话信息，不增加遥测。
- 新批次完整持久化后才发布并清理上一批；失败时旧批次保持可恢复。
- 到期换批只清理本功能拥有的过期缓存，限制缓存总量；不使用 `clear()` 删除其他数据。
- 组件卸载后取消计时器和未完成请求，释放 Object URL，不发布迟到的状态更新。

### R4 用户体验与兼容

- 保留「让这一卷，慢慢显影」、唯一导入按钮、连续片轨、画幅展开和片轨运动，不添加轮播卡片、进度条或营销入口。
- 首屏优先显示本地示意，不等待网络；来源链接不抢占主按钮。
- 支持桌面、平板、390px 手机、键盘操作、减弱动态和 IndexedDB 不可用场景。
- 不修改 `FilmSettings`、Worker 协议、成像算法、用户照片生命周期或输出逻辑。

## Acceptance Criteria

以下为 2026-11-17 更新后的验收项：

- [x] AC1：12 张内置与联网候选均属于审核名单，实际画面、作者、来源和公共领域许可已核验；缺少许可 URL 的公共领域记录使用可信官方链接。
- [x] AC2：片轨在桌面与手机持续匀速左移，悬停、聚焦、拖动和页面隐藏冻结当前位置，减弱动态保持静止；一轮循环没有空白、停顿或可见回跳。
- [x] AC3：到期后只有完整 12 张新批次就绪才替换；上一批仅在新批次持久化后按 ID 删除，失败不丢旧图。
- [x] AC4：离线、超时、无 IndexedDB、部分图片失败均无空白或无限加载，12 张内置经典摄影仍可用。
- [x] AC5：没有用户照片或设置进入公共图片请求；公共示意不进入渲染和导出流程。
- [x] AC6：保留真实作品署名、3:2 几何、键盘可达与 390px 手机布局，不新增控制按钮或横向溢出。
- [x] AC7：单元与真实浏览器测试覆盖 12 张完整批次、连续运动、暂停、首尾衔接、换批、删除、降级和请求隐私。

### 已完成的旧版验收

- [x] AC1：真实 Wikimedia API 返回的许可候选可下载、缓存并显示署名；未知许可或异常内容被拒绝。
- [x] AC2：多张人文照片以连续画幅从右向左推进，可见相邻画幅；页面隐藏、悬停、聚焦、拖动和减弱动态行为符合要求，不抢占导入焦点，标题不与照片重叠。
- [x] AC3：到期后只有完整新批次就绪才替换；上一批仅在新批次持久化后按 ID 删除，失败不丢旧图。
- [x] AC4：离线、超时、无 IndexedDB、部分图片失败均无空白或无限加载，内置示意仍可用。
- [x] AC5：没有用户照片或设置进入公共图片请求；公共示意不进入渲染和导出流程。
- [x] AC6：桌面与 390px 手机保持原有 3:2 几何、无横向溢出和键盘可达，来源许可可识别。
- [x] AC7：单元测试覆盖许可校验、换批原子性、删除所有权、计时器清理和错误降级；真实浏览器验证联网轮换，并运行类型检查和相关回归。

## Out of Scope

- 直接抓取、轮询或热链马格南、哈苏大师赛及其他未明确授权站点。
- 新增服务器、账户、遥测、云端用户照片处理或任意来源图片上传。
- 手动切换按钮、全屏画廊、轮播指示器、自动刷新进度展示或设置页新选项。
- 修复本任务之外的物理／WebGL2 渲染失败，或修改发布、访问控制和部署文件。
