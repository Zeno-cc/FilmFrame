# 产品需求：前端胶片味 / 复古感再进化

## 背景

FilmFrame 已有暗房语义（深底、琥珀、safelight、空暗房胶片条、摄影引言），但整体观感仍偏「干净深色 SaaS + 少量胶片词藻」：

- 材质偏平，缺少纸基、颗粒、暗角、灯下色温层次
- 控件圆角/间距/阴影偏通用 AI 生成 UI
- 空状态有胶片条装饰，但信息密度与真实暗房/接触印相桌仍有距离
- 交互反馈多为纯色 hover，缺少机械/暗房器物感

用户希望：**更有胶片味与复古味，去掉 AI 味**；可参考国内外优秀作品；**可适当引入第三方 JS**（优先轻量、可维护）。

## 目标

1. 打开应用后，第一眼更像「本地数字暗房 / 胶片工作台」，而不是通用 dashboard。
2. 主要界面（顶栏、空暗房、工作区卡片、设置配方、对话框）材质与排版统一，减少塑料感与 AI 模板感。
3. 胶片味通过**可控、可降级**的视觉层实现（纹理、vignette、轻微 grain、边框/压印），不干扰可读性与导出成片本身。
4. 性能与无障碍不回退：`prefers-reduced-motion`、对比度、触控热区、现有 E2E 关键路径保持。

## 非目标

- 不重做导出管线 / 真实 135 成片算法（成片帧风格已有独立链路）。
- 不引入重型 3D、全屏粒子、持续高 CPU 动画。
- 不做成霓虹赛博 / 过度 Instagram 滤镜 UI。
- 不扩大邀请码、更新器、后端 access 范围。

## 用户与场景

- 单人本地处理照片，深色环境长时间使用。
- 桌面为主，手机次之；空态上传、批量卡片、配方面板是高频路径。
- 用户对「胶片/暗房」有情感预期，对花哨特效容忍度低——要「旧物」不要「特效演示」。

## 范围（MVP）

### P0（本轮必做）

1. **全局氛围层**
   - 根层轻微纸基/暗房底噪、边缘 vignette（CSS 为主；JS 仅在需要动态噪点且 CSS 不够时）。
   - Token 微调：更深的暖黑、更「银盐纸」的 paper 色、边线更像氧化金属/卡纸切口。

2. **壳层与顶栏**
   - Header / SessionMeter 更像仪表与胶片暗码，而不是普通导航条。
   - 主按钮质感：减少「纯 flat amber pill」，增加轻微内凹/边缘磨损/压印感（仍保持清晰 CTA）。

3. **空暗房 EmptyDarkroom**
   - 胶片条从「线框装饰」升级为更可信的未曝光/半曝光格、齿孔、边缘光。
   - 引言区更像接触印相卡片或便签，而不是居中 landing hero。

4. **工作区卡片 PhotoCard / 工具条**
   - FRAME 编号、入选态、边框更像接触印相或剪辑台标签。
   - 卡片阴影与底材统一到暗房桌面隐喻。

5. **去 AI 味清单落地**
   - 减少重复的「居中大标题 + 三列步骤 + 通用圆角卡片」模板感。
   - 文案与标签继续中文暗房语境，避免空泛英文装饰堆砌（可保留少量仪器感英文，但要克制）。

### P1（有余力）

- 设置面板 / Recipe 卡片的「配方本」质感。
- 对话框/Sheet 的纸面或灯下投影。
- 极轻的一次入场动效（仅非 reduced-motion）。

### 明确不做

- 改动用户导出 PNG/JPEG 像素算法。
- 新增账号体系或云同步 UI。

## 参考方向（评估用，不要求 1:1 抄）

### 国际

- **VSCO / Analog**：克制胶片色，强编辑气质，少喧闹装饰。
- **Kodak / Portra 品牌数字体验**：暖纸、真实胶片边、产品摄影级留白。
- **Darkroom（iOS）/ Negative Lab Pro 宣传站**：工具感 + 暗房隐喻。
- **Polaroid 官网与 app**：边框、物性、按钮像实体控件。
- **Frameology / 胶片扫描工作室站点**：接触印相桌、标签、序号。

### 国内 / 华语

- **各类胶片相机模拟 app**：齿孔、日期章、轻漏光——学其符号，避其廉价贴纸感。
- **摄影杂志 / 独立胶片实验室站点**（中文排版 + 衬线引言）：学其纸感与编辑排版。
- **小众暗房工作室预约页**：器物摄影、低饱和、真实材质。

### 本项目已有可继承资产

- Token：`--ff-bg-deep`、amber、safelight、display 衬线。
- EmptyDarkroom 胶片运输动画与摄影引言。
- 状态印章 StatusStamp、mono 标签体系。

## 验收标准

1. **观感**：在空态与有照片两种状态下，截图对比「改前/改后」，主观反馈「更有胶片/暗房感，AI 味下降」。
2. **一致性**：颜色与材质全部走 tokens / 共享 CSS 类，禁止页面级硬编码散落无法复用的魔法色。
3. **性能**：空态与 20 张缩略图滚动时，无明显掉帧；不在滚动路径每帧全屏 canvas 重绘（除非有 pause/降级）。
4. **无障碍**：对比度不差于现状；`prefers-reduced-motion: reduce` 时关闭装饰动画与动态噪点。
5. **回归**：`npm run check` 通过；相关 Playwright（空暗房、上传、设置）不因 class 调整而失败，必要时同步测试选择器。
6. **第三方库**：若引入，须记录体积/license、仅用于 UI 氛围、可被 CSS 回退替代的路径写清；默认 bundle 增加应控制在合理范围（目标：非必要不引入运行时依赖，优先 CSS；若引入则单库 gzip 后宜 < 15KB 或可 tree-shake）。

## 约束

- 前端规范见 `.trellis/spec/frontend/`。
- 浏览器内处理边界不变。
- 中文 UI 为主。
- 实现阶段由 **grok 子代理** 主导改 UI，主会话做规划、验收与收口。

## 开放问题（实现前可默认）

1. 氛围强度：默认 **中等**（可感知但不抢内容）；若需开关，做「氛围：克制 / 标准」本地设置（P1）。
2. 第三方 JS：默认 **能不用则不用**；需要程序化 grain 时再引入轻量方案或自研 1 个小模块。
