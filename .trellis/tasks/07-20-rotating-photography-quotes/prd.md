# 摄影大师名言随机轮播

## 目标

免费接入 Wikiquote MediaWiki API 作为摄影名言语料来源，通过人工审核快照为 FilmFrame 提供中文摄影名言随机轮播，不增加 API key、付费套餐、后端或运行时硬依赖。

## 已确认事实

- 没有成熟接口能够同时满足摄影专用、简体中文、免费商用、无需密钥、浏览器可直连和出处可靠。
- Wikiquote MediaWiki API 免费、无需 API key，可按摄影师页面获取内容，但返回的是页面或 Wikitext，不是稳定的名言结构。
- Quotable 免费且支持作者筛选，但实测只有 1 条 Ansel Adams，其他多位摄影师为 0，无法提供足够语料。
- 一言等免费中文接口不是摄影专用；API Ninjas 字段较好，但商业使用需要付费。
- 因此零成本方案必须把“第三方采集”和“用户端轮播”分开：API 提供语料来源，审核快照保证质量和稳定性。

## 推荐范围

- R1. 新增同步脚本，通过 Wikiquote MediaWiki API 拉取预设摄影师白名单页面的修订号、原始 Wikitext 或页面内容。
- R2. 同步脚本只生成候选数据和变更报告，不得自动发布。候选名言经过人工核验、中文翻译和版权标记后，才进入 `photography-quotes.json` 审核快照。
- R3. 每条审核记录包含稳定 ID、英文原文、简体中文译文、摄影师姓名、页面标题、原始作品或访谈信息、Wikiquote 页面 URL、页面修订号、翻译说明和核验日期。
- R4. 浏览器不实时请求 Wikiquote，只读取随应用发布的审核快照；因此没有 CORS、超时、访问地区或第三方故障导致的首屏失败。
- R5. 按固定 24 小时时段从审核快照中自动切换；同一时段内稳定展示，跨时段后自动更新，不提供手动换句或暂停控制。
- R6. 自动更新使用单次可清理计时器，只在下一个 24 小时时段边界触发；自动更新不持续触发读屏器。
- R7. 使用 `<blockquote>` 和 `<cite>` 展示中文名言、摄影师与出处；不显示隐私、API 来源或更新机制等技术说明。
- R8. 同步脚本不携带用户数据，不需要密钥，不新增运行时依赖，也不修改图片上传、Canvas 渲染、真实 135 输出或设置存储。
- R9. 可选的定期同步使用免费的 GitHub Actions 或开发者手动命令；第一版不要求 CI 自动化。

## 第三方 API 边界

- 主采集源：`https://en.wikiquote.org/w/api.php`。
- 中文补充源：`https://zh.wikiquote.org/w/api.php`，仅在存在对应页面时使用。
- 查询只允许项目维护的摄影师页面白名单，不能接受最终用户提供 URL 或页面标题。
- API 返回内容始终视为候选材料，未经审核不得进入用户界面。
- 页面修订号用于识别上游变化；同步失败时保留上一次审核快照。

## 验收标准

- [x] AC1. 同步脚本能够免费请求 Wikiquote 白名单页面，并记录页面 URL、修订号、抓取时间和候选内容。
- [x] AC2. 上游超时、页面不存在、结构变化或返回非法内容时，同步任务明确报告失败且不覆盖现有审核快照。
- [x] AC3. 审核快照校验唯一 ID、作者、原文、中文译文、出处、修订号、来源 URL 和核验日期。
- [x] AC4. 浏览器运行期间不请求 Wikiquote，名言完全使用审核快照，同一 24 小时时段稳定且跨时段自动切换。
- [x] AC5. 界面只显示中文名言、摄影师与出处，不显示手动控制或技术说明。
- [x] AC6. 24 小时更新计时器可清理，390px 移动端无文字遮挡和横向溢出。
- [x] AC7. 测试覆盖同步失败保护、快照校验、24 小时时段计算、自动更新及浏览器无第三方请求。
- [x] AC8. `npm run check`、`npm run test:e2e`、同步脚本测试和 `git diff --check` 全部通过。

## 不在范围内

- 付费 API、API key、Serverless 网关或新增后端。
- 浏览器实时直连 Wikiquote 或每次切换都请求第三方。
- 自动发布未经审核的抓取内容、实时机器翻译、网页全文抓取或用户自定义数据源。
- 用户投稿、收藏、历史记录、分析统计或真实 135 输出变更。

## 已确认决策

采用零成本 Wikiquote 采集加审核快照方案。第三方 API 负责提供语料来源，用户端保持稳定的本地轮播。
