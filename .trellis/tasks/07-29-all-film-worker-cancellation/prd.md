# P0 全型号 Worker 与真实取消

## Goal

让全部 16 款真实 135 在支持环境中离开主线程执行，并让“停止”真正终止正在进行的渲染。

## Requirements

- 所有注册在真实 135 模板表中的胶片，单帧和长条均路由到 Worker。
- Gold 200 可保留现有分层专用路径；其余型号在 Worker 中复现主线程扁平模板合成行为。
- Worker 按胶片类型缓存 overlay 和齿孔 mask 的 `ImageBitmap`，复用现有 URL 注册表、窗口几何、齿孔颜色和帧号规则。
- Worker 或 OffscreenCanvas 不可用、启动失败或素材加载失败时，保留当前主线程回退。
- 停止处理必须终止并重置 Worker；已完成结果保留，未完成 Promise 以可识别的取消结果结束。
- 取消不显示错误提示，不写入迟到结果；下一次渲染可自动创建新 Worker 并正常完成。
- 输出尺寸、透明/背景行为、帧号位置、齿孔颜色、胶片顺序和连续长条拼接不得发生可见回归。

## Acceptance Criteria

- [x] 16 款已注册真实 135 的单帧和长条请求在能力满足时均由 Worker 接收。
- [x] 非 Gold 扁平模板 Worker 输出与现有主线程合成在尺寸、几何和关键像素区域上一致。
- [x] 点击停止会终止当前 Worker，处理中照片恢复可重试状态，已完成照片保持不变。
- [x] 取消不会出现错误通知或接纳迟到结果，随后重新处理能成功。
- [x] 不支持 Worker 的浏览器继续使用主线程渲染。
- [x] 素材与 mask 缓存按胶片复用，切换胶片不会串用资源。
- [x] 单元测试覆盖 16 款路由、资源映射、取消/重建和回退；既有真实 135 视觉端到端测试通过。

## Constraints

- 不引入新依赖，不改变公开设置类型和持久化 schema。
- 不重做真实 135 资产，不调整用户已验收的胶片几何。
- 取消粒度为当前 Worker 实例；批次 generation guard 继续作为迟到结果的第二道保护。
