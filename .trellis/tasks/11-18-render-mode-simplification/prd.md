# 渲染模式减负与命名重构

## Goal

让摄影爱好者不用再区分两个都叫“真实 135”的选项。具备光谱能力的胶片只保留 135 片边，并让两种实际输出用稳定、准确、可区分的中文名称表达。

## Background

- 当前界面有三个正交字段：`frameRenderMode`（片边模式）、`edgeRenderMode`（底片渲染）、`imagingMode`（成像方式）。
- “片边模式：真实 135 / 经典片边”中的“真实 135”是父级画幅模式；“底片渲染：真实 135 贴图 / 物理底片”中的“真实 135 贴图”只是该父模式下的模板片边实现。两处名称重叠，用户无法判断层级。
- 29 款胶片中，24 款具备光谱能力，5 款为 blocked：ColorPlus 200、Pro Image 100、Superia 400、T-Max 400、P3200。
- `frameRenderMode='classic'` 与 `edgeRenderMode='legacy-template'` 不是同一件事。“经典片边”是程序化边框路径；`legacy-template` 是 135 画幅下的模板/兼容片边路径，9 款有光谱但无已验收物理片边的胶片仍依赖它。
- 用户已确认：经典片边仅在具备光谱能力的胶片上移除；非光谱胶片继续保留经典片边。
- 生成式模板来源已记录为 user-provided generated film-border artwork，但仓库未记录具体生成工具、提示词和权利归属。因此 UI 不再用“真实”修饰模板，也不直接写“AI”。

## Confirmed Decisions

- 具备光谱能力的 24 款胶片：固定 `frameRenderMode='real135'`，不显示“经典片边”入口，也不再显示只有单一有效值的“片边模式”二选一。
- 5 款非光谱胶片：保留“135 画幅 / 经典边框”选择；选择经典边框时隐藏 135 片边与物理参数。
- 用户可见命名：
  - `frameRenderMode='real135'` → **135 画幅**
  - `frameRenderMode='classic'` → **经典边框**（仅非光谱胶片）
  - `edgeRenderMode='legacy-template'` → **模板片边**
  - `edgeRenderMode='physical135'` → **物理片边**
  - 原“底片渲染”控件 → **片边方式**
- 新增一行简短说明：**模板整幅套用，物理按片门与齿孔生成**。
- 内部枚举值、localStorage 键和渲染签名键保持不变。经典渲染器继续为 5 款非光谱胶片与旧数据服务。
- 旧设置/配方在光谱胶片上出现 `classic` 时，迁移为 `real135 + legacy-template + legacy`，并用现有提示机制告知一次。

## Requirements

### R1 按胶片能力收敛片边入口

- 使用现有 `supportsSpectralStock(brandText)` 判断范围，不新增重复能力表。
- 光谱胶片：不渲染“经典边框”按钮或“片边模式”控件；始终显示“片边方式”。
- 非光谱胶片：显示“135 画幅 / 经典边框”；选择 135 画幅时显示“片边方式”，选择经典边框时隐藏 135 片边和物理参数。
- 切换胶片、加载偏好或应用配方后，不得留下“光谱胶片 + classic”或“classic + physical135”的冲突状态。

### R2 命名与层级

- “片边”区块内使用“片边方式”选择模板片边或物理片边，并从“高级渲染设置”提升到常规层级；物理参数仍留在高级设置。
- 配方摘要、错误提示、App 长条提示同步使用新名称，不再出现“真实 135”“真实 135 贴图”“物理底片”“底片渲染”。
- 不在界面新增卡片、教学段落或额外弹窗；只保留一行 helper。
- “模板片边”同时覆盖 16 个 PNG 模板和 11 个程序化兼容片边，不写成“AI 贴图”或“实测扫描”。

### R3 迁移与兼容

- 保持 `frameRenderMode`、`edgeRenderMode`、`imagingMode` 的持久化值与渲染键不变。
- 旧光谱胶片偏好/配方中的 `classic` 在读取或应用时显式迁移，不得静默丢弃。
- 旧非光谱胶片偏好/配方中的 `classic` 保持不变。
- 迁移只改变一次模式选择；不批量重写用户已保存的配方，不改索引、不清理用户数据。
- `legacy-template` 路径、模板 PNG、兼容片边、物理片边与光谱算法均不得改动。

### R4 验证

- 单测覆盖光谱/非光谱判断、旧偏好与配方迁移、冲突组合归一化。
- Playwright 覆盖光谱胶片无经典入口、非光谱胶片仍可选经典、两种片边方式命名正确、摘要与错误文案一致。
- 现有渲染结果在同一 `real135/edgeRenderMode/imagingMode` 组合下保持不变。

## Acceptance Criteria

- [x] AC1：Portra 400、Gold 200 等光谱胶片不再显示“片边模式”“真实 135”“经典片边”；只显示“片边方式：模板片边 / 物理片边”。
- [x] AC2：ColorPlus 200 等 5 款非光谱胶片可选择“135 画幅 / 经典边框”；选择经典边框后不显示片边方式与物理参数。
- [x] AC3：界面、摘要和错误提示不再出现“真实 135”“真实 135 贴图”“物理底片”“底片渲染”作为模式名称。
- [x] AC4：旧光谱偏好或配方中的 `classic` 加载后变为 `real135 + legacy-template + legacy`，并出现一次可理解提示；非光谱 `classic` 不被迁移。
- [x] AC5：内部枚举、localStorage 键和渲染签名键未改变；同组合渲染结果不变。
- [x] AC6：helper 文案出现一次，不新增卡片或多余说明；桌面与 390px 设置面板无溢出。
- [x] AC7：单元测试、Playwright 相关回归、类型检查和生产构建通过。

## Out of Scope

- 全局删除经典片边、经典渲染器或经典专属字段。
- 删除 `legacy-template`、PNG 模板、兼容片边或物理片边能力。
- 修改光谱/物理算法、Worker 协议、渲染预算或输出尺寸。
- 重命名内部枚举值、存储键或渲染签名键。
- 修改 provenance 记录或把模板宣称为实测扫描。
- 重新设计整个设置面板或移动端信息架构。

## Risks / Deferred

- 条件显示会让“画幅样式”随胶片切换出现或消失；这是用户已确认的范围取舍。
- `supportsSpectralStock` 中的 blocked 状态是唯一范围依据；未来型号状态变化时 UI 自动跟随。
- 删除经典渲染死代码应另立任务，需先确认 5 款非光谱胶片不需要它。
- 模板素材权利仍为 owner-review，本任务不改变发布判断。
