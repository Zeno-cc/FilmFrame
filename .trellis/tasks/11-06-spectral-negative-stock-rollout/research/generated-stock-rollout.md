## Resource and fixture contract

- Film TC arrays use the selected film's sensitivity, four-parameter adaptation window, D55 reference illuminant and the fixed active input xy compression. Surface adaptation is disabled.
- Film log-exposure, raw, normalized, and pre-DIR curves remain separate. Development uses normalized curves and pointwise donor-row/receiver-column DIR with amount 1 and zero diffusion.
- Base/channel spectral data are finite after export, accompanied by independent film and paper complete-measurement validity masks. Invalid wavelengths transmit zero rather than silently becoming valid zero density.
- The selected paper's fitted characteristic model supplies the paper curves; the exact TH-KG3 filtered enlarger uses that pair's full-precision C/M/Y entry.
- Mid-gray is a single scalar reciprocal geometric mean of three raw paper responses. The upstream mid-gray density is derived with the raw, unnormalized film curves and no DIR. The scalar and masked-integral reconstruction are compared with the upstream factor.
- The fixed output is encoded sRGB with measured OkLch compression. The 64x720 OkLch maximum-chroma table, 81-sample observer, matrices, and common table hashes are preserved. Legacy D55/D50 array names are retained only for this still-paper schema; generic `proPhotoToXyzReferenceCat16`, `viewingIlluminant`, and `xyzViewingToSrgbCat02` aliases make the illuminants explicit.
- Each pair has gray-ramp16, green-patch8, and a deterministic 64x64 synthetic-sRGB/ProPhoto input. `filmRaw`, `negativeDensity`, `paperLogExposure`, `paperDensity`, and `printRgb` are independently generated by the pinned upstream controlled process. The exporter separately reconstructs every stage from the exported arrays and compares it with upstream before emitting resources.
- The comparison is elementwise `abs(actual - expected) <= atol + rtol * abs(expected)` after shape/finiteness checks. `filmRaw`, `negativeDensity`, and `paperLogExposure` use `atol=2e-8`, `rtol=2e-9`; `paperDensity` uses `atol=5e-8`, `rtol=5e-9`; `printRgb` uses `atol=1e-7`, `rtol=1e-8`. These are strict float64 exporter-reconstruction tolerances, not borrowed TypeScript/WebGL thresholds and not a claim that all future runtimes will meet them.

## Portra 400 compatibility and known historical discrepancy

The Portra 400 resource is compared payload-for-payload with the existing `services/spectral/resources/portra-setup.json` for every original numeric array. The fixture manifest also checks the four pinned historical baseline files by source and output payload hashes.

The historical gray print-RGB discrepancy is not removed or relabeled as success: the current upstream OkLch run retains 48 darkest-column violations at the historical `atol=1e-6`, `rtol=1.5e-3` comparison. The new current-controlled source-specific fixtures are separate evidence, and no historical baseline is regenerated. Exact values and digests are in `fixtures/manifest.json` under the Portra 400 pair and in the numerical report.

## Execution result

The exporter must be run with Python `-I` using the supplied isolated Python 3.13.12 environment. No downloaded source is run from the repository or a downloaded checkout as the working directory; NumPy/JIT cache output is directed to a separate owned temporary work directory.

See `numerical-stock-validation.json` for the completed-run result. Presence of this document or a generated directory alone is not validation; the recorded comparisons and execution record are the evidence.

## Vision3 and unsupported-stock boundary

Vision3 is deferred, not added by this exporter. The still-paper schema must not be used for `kodak_2383`: it requires K75P viewing and its own CAT02-to-sRGB matrix, while Vision3 200T and 500T require tungsten camera-reference transforms in addition to the D55 path. A follow-up must explicitly generalize the K75P spectrum/normalization, D55/T reference handling, exact Kodak 2383 fitted paper arrays, validity masks, filters and mid-gray calibration, and validate each Vision3 pair separately before registration. No Vision3 numerical support is inferred from these still-paper results.

Exact ColorPlus, Pro Image, Superia 400, T-Max 400, and P3200 remain unavailable. B&W and positive films have separate semantics. CineStill's distinguishing spatial/back-reflection appearance is not supplied by a pointwise Vision3 setup. Full native grain, halation/scatter, spatial DIR diffusion, glare, lens/scanner blur and unsharp effects are disabled here; no full native-effects parity is claimed.
