# FilmFrame Display

`filmframe-display.woff` is a 500-weight display subset derived from Adobe Source Han Sans CN Medium. It contains only the FilmFrame Chinese workspace headings and printable ASCII. The primary family name was changed to `FilmFrame Display`; the font remains under SIL Open Font License 1.1, included in `OFL.txt`.

- Official source: https://github.com/adobe-fonts/source-han-sans/blob/release/SubsetOTF/CN/SourceHanSansCN-Medium.otf
- Official license: https://github.com/adobe-fonts/source-han-sans/blob/release/LICENSE.txt
- Copyright: 2014–2025 Adobe, with Reserved Font Name `Source`.
- Modification: glyph subsetting, WOFF conversion, and reserved-name replacement; no letterform redesign.

The subset is intentionally restricted to its current display strings. Extend it from the official source before using this family for new Chinese display copy; normal body text and controls use the system UI stack.
