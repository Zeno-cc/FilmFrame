## 1. 执行原则

本路线图是 UI/组件重构，不是渲染引擎或产品能力重写。每个阶段都要有独立可回滚边界和验证门；先抽展示层，再移动布局，最后补齐浏览器测试。`App.tsx` 在中间阶段仍是 controller，最终目标是约 500–650 行，单个展示组件建议不超过 250 行。

### 1.1 已确认基线

截至本计划创建时：

- `App.tsx` 约 1967 行，承担上传、EXIF、处理/停止/重试、预览、裁切、排序、配方、分享、下载、通知和整页布局。
- 独立 UI 组件只有 `components/CropEditor.tsx`；图标均为 `App.tsx` 内联 SVG。
- 当前工作区有用户未提交的 P0/P1/free-crop 改动，禁止 `git reset --hard`、`git clean -fd`、覆盖或回退这些修改。
- `npm run test`：16 个 Vitest 文件、118 项断言通过。
- `npm run typecheck`：通过。
- `npm run build`：通过，Vite 转换 60 个模块。
- 当前无 Playwright、无 E2E 配置；`public/alipay.jpg` 已知不可解析。

上述命令结果是本轮计划的基线证据；后续实现若结果变化，必须记录原因而不是修改门禁来掩盖差异。

### 1.2 不可破坏契约

1. UI 继续通过 `filmWorkerClient.processImage()` 与 `generateFilmStrip()` 调用渲染门面。
2. 保留 `renderResult` 的 MIME/settings key/stale 判定、generation gate、晚到结果回收和 Object URL 所有权。
3. 原图、成片、transform 不进入 localStorage；偏好 key `filmFrame.preferences.v1`、配方 key `filmFrame.recipes.v1` 和白名单规则不变。
4. 图片数组顺序是帧号、长条顺序、ZIP 序号和 stale key 的唯一业务顺序来源。
5. 单张处理继续逐张串行，单项失败不阻断其他项；“停止后续”不承诺立即中断当前 Canvas。
6. 删除、替换、关闭预览、清除长条和卸载时继续回收 Object URL；classic 主线程与 Gold 200 real135 Worker 能力策略不变。
7. 不改变 Canvas/Worker 像素、输出尺寸、质量、随机纹理、下载命名、ZIP 格式、安全清洗规则或既有 Vitest 断言。

## 12. 风险登记与应对

| 风险 | 触发点 | 应对 |
| --- | --- | --- |
| 组件拆分引入竞态 | callback/URL 生命周期被移动 | 先保留 App controller；按 image ID 合并；每阶段跑单测和严格模式 |
| stale/下载误判 | 组件复制 render key | 所有判断集中在现有 selector/service；组件只接收 derived props |
| Worker 与主线程行为漂移 | 为视觉重构顺手改 renderer | 将 `filmEngine`/`filmWorker` 列为禁止修改区域，另开任务处理 |
| 处理中的删除/停止回归 | 新 Sheet/底栏覆盖 gate | 复用 `isImageRemovalAllowed`、generation gate 和现有 callback；E2E 覆盖 |
| Tailwind 样式被 purge | 新组件目录未扫描 | 先更新 `@source`，在每阶段生产构建后检查样式 |
| 捐赠二维码破图 | 依赖当前 `public/alipay.jpg` | `onError` fallback，正确资产由所有者后续提供 |
| 移动端焦点/滚动丢失 | 新 Drawer/Sheet 自行实现 | 共享 `ModalSurface`，测试 focus trap、Escape、restore、scroll lock |
| 大图性能下降 | 卡片 render 读取 Blob/新增 decode | 稳定 `key={img.id}`，不在 render 读 Blob，不增加无 debounce 的预览调用 |

## 13. 明确不做

- 后端、登录、云同步、IndexedDB、路由、全局状态库、PWA、多语言。
- 新胶片型号、真实色彩模拟、任意角旋转、透视、AI 裁切、HEIC 转码。
- Canvas 算法、输出尺寸/质量、随机纹理、下载命名、ZIP 格式、localStorage schema。
- 远程字体、远程图片、遥测、图片上传、未经授权的 demo 摄影素材。
