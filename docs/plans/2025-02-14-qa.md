## 1. QA 目标与门禁原则

QA 要证明的是“UI 重构完成且业务契约未退化”，而不是只证明页面看起来新。每个阶段完成前运行快速门禁；最终交付同时提供单元/服务、浏览器旅程、响应式截图、无障碍、性能、隐私和资产证据。

禁止通过删除、跳过、放宽断言或改写业务测试来通过门禁。发现失败时先定位是展示层、编排层还是既有 service 契约变化。

## 3. 测试分层

### 3.1 既有服务与纯函数回归

保留全部 16 个 Vitest 文件和断言，重点确认：

- `workflowState`：状态推导、批次选择、主操作、移动和删除 gate。
- `renderResult`：settings key、MIME、stale/current、文件名清洗、strip key。
- `renderTransform`/`filmGeometry`：pan/zoom/quarter-turn 和帧几何不变。
- `previewNavigation`/`previewDownload`：循环导航、源选择、命名和下载条件。
- `previewRenderController`：debounce、generation、旧 URL 回收。
- `filmWorkerClient`、`imageBatch`、`renderBudget`：Worker fallback、逐张任务、容量预算。
- `settingsStorage`/`recipeStorage`：schema、白名单、12 条上限、40 字和同名覆盖。
- `uploadFiles`、`zip`、`shareArtifact`：格式限制、URL 回收、ZIP 顺序和分享失败。

### 3.2 组件/交互测试

若拆出的 primitive 有纯行为，可用现有 Vitest 环境补充最小测试；不要为了 UI 引入全局状态库。重点是：按钮 disabled/label、StatusStamp 映射、ModalSurface 焦点协议、Sheet scroll lock 和 CTA 去重。

### 3.3 浏览器 E2E

使用 Playwright 固定 viewport、合成 fixture 和稳定选择器（优先 `role`、`aria-label`、`data-testid`），避免依赖 Tailwind class 或坐标点击。每条旅程记录 trace、失败截图和 console。

## 4. E2E 旅程清单

### E2E-01 桌面空态

- viewport：1440×1000。
- 验证 Header、`LOCAL ONLY`、选择照片、Workspace 标题/Tab 和右侧 Inspector 可见。
- 验证空态主按钮是真实 button，Enter/Space 可触发文件选择。

### E2E-02 手机空态

- viewport：390×844（另跑 360×800）。
- 首屏看到品牌、隐私说明、选择照片和固定底部主操作。
- 验证无横向滚动，底栏包含 safe-area，设置入口可打开 Sheet。

### E2E-03 上传格式与数量

- 使用 `landscape.jpg`、`portrait.png`、`square.webp`。
- 验证卡片数量、文件名、顺序和 `01 / N` 标识。
- 混合不支持文件时验证 warning/error，不创建无效卡片且 URL 被回收。

### E2E-04 排序与帧号

- 通过上移/下移按钮调整顺序，验证 `<ol>` 顺序、Frame 标识、strip rail 和后续 ZIP 顺序一致。
- 桌面再验证拖拽插入 marker；首项上移、末项下移禁用且有可解释 label。

### E2E-05 单张冲洗

- classic 模式处理两张合成 fixture。
- 验证状态从待冲洗/排队中/冲洗中到已出片，单张失败不阻断另一张。
- 验证 Header session summary、Inspector CTA、aria-live 摘要同步更新。

### E2E-06 设置变化与 stale

- 先完成一张，再修改颗粒、输出格式或片边设置。
- 验证立即显示 `需重洗`、detail 文案、下载入口消失，重新冲洗后恢复 current。
- 验证旧 artifact 不会伪装成最新结果。

### E2E-07 Preview 审片

- 打开 Preview，验证 Before/After、左右导航循环、Escape 关闭和焦点恢复。
- 即时 preview 生成期间保留上一张可用图像并显示小型提示。
- stale/未处理不显示下载/分享伪入口；分享失败不自动下载。

### E2E-08 Crop Editor

- 打开构图编辑器，验证拖动、100%–300% zoom、wheel 锚点、方向键/Shift、90°旋转、Reset、Cancel、Done。
- Cancel 不修改 transform；Done 只提交一次并触发后续重洗；横/竖/方图在 390×844 与 1440×1000 无遮挡。

### E2E-09 Mobile Settings Sheet

- 打开 Sheet，验证初始焦点、Tab 闭环、Escape、背景点击、焦点恢复和背景 scroll lock。
- 验证 `胶片 / 输出 / 配方` 三 Tab 不卸载已填写字段，Sheet footer 固定。
- Sheet 打开时页面底栏隐藏或 inert；processing 时不会因背景点击误触停止。

### E2E-10 Film Strip

- 切换 `FILM STRIP`，验证未生成 Stage、顺序 rail、生成中提示、current 工具条和 stale 提示。
- 修改图片顺序/设置后旧长条失效并显示 `需重新生成`；current 才能预览/下载。

### E2E-11 部分失败与重试

- 使用可控失败 fixture 或 mock，使一张失败、其余成功。
- 验证错误详情、卡片 `冲洗失败`、重试动作、已成功结果保留以及批次完成摘要。

### E2E-12 停止后续与导出 gate

- 批量处理中点击 `停止后续`，验证当前任务语义、未开始项回到待冲洗/需重洗、晚到结果按 generation 规则处理。
- 单张 ZIP 导出期间重复点击，验证按钮 disabled、真实 `exportMessage`、无重复下载；浏览器阻止下载时有可行动错误。

### E2E-13 Support QR fallback

- 拦截或替换 `/alipay.jpg` 为解码失败响应。
- 验证显示“二维码暂不可用，请在资源替换后重试。”，无 broken image icon、无白底营销弹窗、无伪造二维码。

### E2E-14 reduced motion

- 使用 `prefers-reduced-motion: reduce` context。
- 验证没有循环位移/缩放/噪点动画，状态仍通过文字和图标理解，Modal/Toast 可正常关闭。

### E2E-15 长内容与 200% zoom

- 使用超长中文/英文文件名、12 条配方和 20 张图片。
- 验证 200% 浏览器缩放下无双向滚动、文字不溢出、关键动作仍可达，20 张卡片滚动不出现明显卡顿。

## 5. Fixture 与测试数据

## 7. 无障碍验收

- [ ] 正文对比度达到 WCAG AA：普通文字至少 4.5:1，大字号至少 3:1。
- [ ] 所有交互目标移动端至少 44×44px；文本不因缩放或长词溢出父容器。
- [ ] 上传是 button/label 语义，可用 Enter/Space；Tab 顺序符合视觉工作流。
- [ ] 模式/分段控件使用 `tab`、`radio` 或 `aria-pressed`，选中状态可读。
- [ ] 所有 icon-only 控件有 `aria-label` 和 tooltip/title；装饰齿孔、噪点、英文微标签 `aria-hidden`。
- [ ] 状态有文字和图标，不能只依赖颜色；processing/exporting 摘要使用 `aria-live="polite"`，不逐帧刷屏。
- [ ] Dialog/Drawer/Sheet 有 `aria-modal`、labelledby/describedby、初始焦点、Tab 闭环、Escape 和焦点恢复。
- [ ] Preview 支持左右方向键和 Escape；Crop 支持键盘平移、Shift 大步和 range aria-label。
- [ ] 拖拽排序有上移/下移等价操作；首尾禁用按钮有解释性 label。
- [ ] 200% zoom、横屏手机和 reduced motion 仍可完成主流程。

## 8. 性能、隐私与资产验收

### 性能

- [ ] UI 重构不新增图片 decode、Object URL 或 render 内 Blob 读取。
- [ ] 卡片使用稳定 `key={img.id}`；不对图片做 blur/filter 动画，不为每张卡片增加高成本 backdrop-filter。
- [ ] Inspector 设置变化保留现有 preview debounce；不新增无 debounce 的渲染调用。
- [ ] 20 张 4K 图片滚动和打开 Preview 无明显冻结；Worker fallback、超时和卸载行为不变。

### 隐私

- [ ] 没有新遥测、分析、错误上报、远程字体、远程图片或图片上传。
- [ ] Header/空态有 local-only 说明；用户文件名不发送到外部链接。
- [ ] Worker 只读取同源静态资源；偏好之外不写入图片、成片或 transform。

### 资产

- [ ] Logo/空态/装饰使用内联 SVG 或本地小资源；不把胶片 overlay 当 UI 背景。
- [ ] `/alipay.jpg` 解码失败有 fallback；正确二维码由项目所有者提供，不由实现者伪造。
- [ ] 不提交未经授权的 demo 摄影素材；检查发布包中 `.DS_Store` 和中间 PNG。
