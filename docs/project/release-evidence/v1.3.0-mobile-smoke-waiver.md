# FilmFrame v1.3.0 Physical Mobile Smoke Waiver

## Decision

On 2026-08-10, the project owner explicitly authorized the `v1.3.0` release
to proceed without completing the physical iPhone Safari and Android Chrome
smoke journeys defined in `docs/project/browser-mobile-smoke.md`.

This document records a one-release exception. It does not claim that either
physical-device journey passed, and it does not weaken the default release gate
for later versions.

## Candidate Context

- Application candidate revision: `838e4b0afcf5f35a285553c7e9a0cb8947e6af26`
- Candidate URL: `filmframe-rc.astrocean.space`
- Candidate deployment assets revision: `0abf2b1`
- Automated invitation redemption, session, runtime configuration, replay,
  loopback, OpenResty, Cloudflare HTTPS/cache, and production-isolation probes:
  passed before the waiver decision.

## Accepted Residual Risk

- Physical iPhone Safari rendering, download, rotation, memory pressure, and
  local-only network behavior were not evidenced for this release.
- Physical Android Chrome rendering, download, rotation, memory pressure, and
  local-only network behavior were not evidenced for this release.
- Automated Chromium, Firefox, desktop WebKit, Access, release-contract, and
  deployment gates remain mandatory and must pass before the tag is created.

## Release Handling

The stable release must still use the immutable Git tag, GitHub Actions build,
signed provenance, canonical manifest, host updater, automated rollback, and
post-cutover production verification. No physical PASS record may be derived
from this waiver.
